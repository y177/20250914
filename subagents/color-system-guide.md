# 🌈 Sub-Agent 색상 체계 가이드 (Color System Guide)

## 🎯 **색상 체계 개요**

Sub-Agent 시스템에 도입된 색상 체계는 **시각적 구분성**과 **직관적 인식**을 위해 설계되었습니다. 각 색상은 해당 Agent의 **핵심 기능**과 **심리적 연상**을 바탕으로 선택되었습니다.

---

## 🎨 **Agent별 색상 매핑**

### **🔵 SysMonitor - 파란색 (Blue)**
- **의미**: 신뢰성, 안정성, 전문성
- **심리적 효과**: 차분함, 신뢰감, 기술적 전문성
- **적용 이유**: 시스템 모니터링은 **안정성과 신뢰성**이 핵심
- **사용 맥락**: 
  - 시스템 상태 표시
  - 모니터링 대시보드
  - 안정성 관련 알림

### **🟢 PerfOptimizer - 녹색 (Green)**  
- **의미**: 효율성, 최적화, 건강한 상태
- **심리적 효과**: 성장, 향상, 긍정적 변화
- **적용 이유**: 성능 최적화는 **시스템 건강과 효율성** 향상
- **사용 맥락**:
  - 성능 개선 결과
  - 최적화 성공 표시
  - 시스템 건강도 표시

### **🟡 AutoFlow - 노란색 (Yellow)**
- **의미**: 에너지, 자동화, 활력
- **심리적 효과**: 활동성, 창의성, 주의 집중
- **적용 이유**: 자동화는 **역동성과 업무 효율성**을 상징
- **사용 맥락**:
  - 자동화 작업 진행
  - 워크플로우 활성 상태
  - 에너지 효율성 표시

### **🟣 MainScheduler - 보라색 (Purple)**
- **의미**: 전문성, 계획성, 체계적 관리
- **심리적 효과**: 고급스러움, 전문성, 체계성
- **적용 이유**: 유지보수 스케줄링은 **전문적 계획과 체계적 관리** 필요
- **사용 맥락**:
  - 유지보수 계획 표시  
  - 스케줄링 상태
  - 전문적 관리 영역

### **🔴 DataCrawler - 빨간색 (Red)**
- **의미**: 중요성, 실시간성, 긴급성
- **심리적 효과**: 주의 집중, 긴박감, 중요성 인식
- **적용 이유**: 의료 데이터 수집은 **실시간성과 중요성**이 핵심
- **사용 맥락**:
  - 긴급 의료 정보 알림
  - 실시간 데이터 수집 상태
  - 중요 정보 강조

## 📊 **상태 표시 색상 체계**

### **운영 상태 색상**
| 상태 | 색상 | 의미 | 적용 시점 |
|------|------|------|-----------|
| **정상** | 🟢 | 모든 기능이 정상 작동 | 성능 목표 달성, 오류 없음 |
| **주의** | 🟡 | 성능 저하 또는 경미한 이슈 | 성능 80-95%, 경고 발생 |
| **경고** | 🟠 | 즉시 주의가 필요한 상태 | 성능 60-80%, 오류 증가 |
| **위험** | 🔴 | 심각한 문제 또는 중단 상태 | 성능 <60%, 시스템 장애 |
| **비활성** | ⚫ | Agent가 비활성화된 상태 | 수동 중지, 유지보수 모드 |

### **우선순위 색상**
| 우선순위 | 색상 | 대응 시간 | 적용 예시 |
|----------|------|----------|----------|
| **긴급** | 🔴 | 즉시 (15분 이내) | 시스템 다운, 중요 데이터 손실 |
| **높음** | 🟠 | 1시간 이내 | 성능 저하, 보안 경고 |
| **보통** | 🟡 | 4시간 이내 | 일반 최적화, 정기 점검 |
| **낮음** | 🟢 | 24시간 이내 | 개선 제안, 예방적 조치 |
| **정보** | 🔵 | 참고용 | 통계, 보고서, 일반 알림 |

## 🔄 **색상 적용 규칙**

### **일관성 원칙**
1. **Agent 고유 색상**: 각 Agent는 고유한 색상을 유지
2. **상태 우선**: 상태 표시가 Agent 색상보다 우선
3. **맥락 고려**: 사용 맥락에 따른 적절한 색상 선택
4. **접근성**: 색약자를 고려한 충분한 대비와 텍스트 병행

### **혼합 상황 처리**
- **여러 Agent 동시 표시**: 각각의 고유 색상 유지
- **상태와 Agent 색상 충돌**: 상태 색상 우선, Agent명으로 구분
- **경고 상황**: 빨간색 우선, 해당 Agent 정보 병기

## 🛠️ **구현 가이드라인**

### **대시보드 적용**
```markdown
# 정상 상태
🟢 🔵 SysMonitor: 정상 운영 중 (CPU: 45%, Memory: 60%)

# 주의 상태  
🟡 🟢 PerfOptimizer: 최적화 진행 중 (성능 개선: 85%)

# 경고 상태
🟠 🟡 AutoFlow: 일부 작업 지연 (큐 대기: 15개)

# 위험 상태
🔴 🔴 DataCrawler: 수집 실패 다수 (실패율: 25%)
```

### **알림 메시지 형식**
```markdown
🔴 [긴급] DataCrawler: 의료진 필수 정보 업데이트 감지
🟠 [경고] SysMonitor: 메모리 사용률 85% 도달  
🟡 [주의] PerfOptimizer: 최적화 권장 항목 5개 발견
🟢 [정상] MainScheduler: 주간 유지보수 성공적 완료
🔵 [정보] AutoFlow: 금주 자동화 절약 시간 32시간
```

## 📈 **색상 체계의 효과**

### **개선된 사용자 경험**
- **빠른 인식**: 색상으로 즉시 상태 파악 가능
- **직관적 구분**: Agent별 기능을 색상으로 연상
- **우선순위 명확화**: 중요도에 따른 즉각적 판단
- **시각적 조직화**: 복잡한 정보의 체계적 정리

### **운영 효율성 향상**
- **모니터링 효율성**: 한눈에 전체 시스템 상태 파악
- **대응 속도 개선**: 색상 기반 우선순위 즉시 판단  
- **인지 부하 감소**: 텍스트 읽기 전 색상으로 선별
- **커뮤니케이션 개선**: 팀 간 상태 공유 시 명확성 증대

---

## 🔮 **향후 확장 계획**

### **추가 색상 활용**
- **🟤 브라운**: 로그 관리, 데이터 아카이브 Agent
- **🟪 분홍**: 사용자 경험, 인터페이스 최적화 Agent  
- **⚪ 회색**: 백업, 복구 전담 Agent
- **🟫 주황**: 보안, 방화벽 관리 Agent

### **고급 시각화**
- **그라데이션**: 성능 수치의 연속적 표현
- **애니메이션**: 실시간 상태 변화 시각화
- **패턴**: 색상 + 패턴으로 더 세밀한 구분
- **테마**: 라이트/다크 모드별 최적화된 색상 팔레트
