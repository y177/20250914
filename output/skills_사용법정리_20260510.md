## 1. 로컬 스킬 (`~/.claude/skills/`)

## 2. 로컬 커맨드 — SuperClaude (`~/.claude/commands/sc/`)

> `/sc:명령어` 슬래시 커맨드로 호출. SuperClaude 에코시스템 통합.

| 커맨드              | 기능                                                                                                                  | 호출 방법                                                                                                  |
| ------------------- | --------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| **sc:analyze**      | 코드 품질·보안·성능·아키텍처 종합 분석                                                                                | `/sc:analyze [대상] [--focus quality\|security\|performance\|architecture]`                                |
| **sc:build**        | 빌드·컴파일·패키징. 오류 처리 및 최적화 포함                                                                          | `/sc:build [대상] [--env dev\|prod]`                                                                       |
| **sc:cleanup**      | 데드 코드 제거, 프로젝트 구조 최적화                                                                                  | `/sc:cleanup [대상]`                                                                                       |
| **sc:design**       | 시스템 아키텍처·API·컴포넌트 인터페이스 설계                                                                          | `/sc:design [시스템명]`                                                                                    |
| **sc:document**     | 특정 컴포넌트·기능에 대한 집중 문서 생성                                                                              | `/sc:document [대상]`                                                                                      |
| **sc:estimate**     | 태스크·기능·프로젝트 개발 공수 산정                                                                                   | `/sc:estimate [작업내용]`                                                                                  |
| **sc:explain**      | 코드·개념·시스템 동작 명확한 설명                                                                                     | `/sc:explain [코드\|개념]`                                                                                 |
| **sc:git**          | 지능형 커밋 메시지 생성 및 브랜치 관리 Git 작업                                                                       | `/sc:git [커밋\|브랜치\|PR 등]`                                                                            |
| **sc:implement**    | 기능 구현. 페르소나 자동 활성화 + MCP 통합 지원                                                                       | `/sc:implement [기능명]`                                                                                   |
| **sc:improve**      | 코드 품질·성능·유지보수성 체계적 개선                                                                                 | `/sc:improve [대상]`                                                                                       |
| **sc:index**        | 프로젝트 종합 문서·지식베이스 생성                                                                                    | `/sc:index`                                                                                                |
| **sc:load**         | 프로젝트 컨텍스트·설정·의존성 로드 및 분석                                                                            | `/sc:load`                                                                                                 |
| **sc:spawn**        | 복잡한 태스크를 서브태스크로 분해 후 조율 실행                                                                        | `/sc:spawn [작업]`                                                                                         |
| **sc:task**         | 지능형 워크플로우 관리 + 세션 간 지속성을 갖춘 복잡 태스크 실행                                                       | `/sc:task [태스크명]`                                                                                      |
| **sc:test**         | 테스트 실행·리포트 생성·커버리지 관리                                                                                 | `/sc:test [대상]`                                                                                          |
| **sc:troubleshoot** | 코드·빌드·시스템 동작 문제 진단 및 해결                                                                               | `/sc:troubleshoot [문제]`                                                                                  |
| **sc:workflow**     | PRD·기능 명세서 → 단계별 구현 워크플로우 생성. 전략(systematic/agile/mvp)·출력 형식(roadmap/tasks/detailed) 선택 가능 | `/sc:workflow [PRD파일\|기능설명] [--strategy systematic\|agile\|mvp] [--output roadmap\|tasks\|detailed]` |

### 6-1. 메인 루프 6단계

```
/gsd-map-codebase → /gsd-new-project → /gsd-discuss-phase N →
/gsd-plan-phase N → /gsd-execute-phase N → /gsd-verify-work N → /gsd-ship N →
/gsd-complete-milestone → /gsd-new-milestone (다음 버전)
```

| 커맨드                     | 기능                                                                                         | 호출 방법                 |
| -------------------------- | -------------------------------------------------------------------------------------------- | ------------------------- |
| **gsd-new-project**        | 프로젝트 초기화: 질문→리서치→요구사항→로드맵 생성. 기존 코드 있으면 먼저 `/gsd-map-codebase` | `/gsd-new-project`        |

| **gsd-plan-phase**         | 리서치→계획→검증 루프. 계획이 기준을 통과할 때까지 자동 반복                                 | `/gsd-plan-phase [N]`     |
| **gsd-execute-phase**      | 병렬 웨이브로 계획 실행. 각 실행자가 신선한 200K 컨텍스트. 각 태스크별 원자 커밋             | `/gsd-execute-phase [N]`  |
